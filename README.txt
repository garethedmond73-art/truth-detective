THE TRUTH DETECTIVE — FIRST PROTOTYPE

Installable Progressive Web App. Host on HTTPS (GitHub Pages), open in Android Chrome, then choose Add to Home screen / Install app.

Features: perspectives from Scripture, Science, Philosophy and Human Experience; an evidence ledger with source, support, challenge and assessment fields; local browser storage.

Limitations: does not automatically search external sources. It organises evidence and keeps uncertainty visible. Notes are stored in this browser on this device; clearing browser data can erase them.
