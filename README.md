# The Truth Detective

An open-minded evidence notebook for exploring big questions through scripture, science, philosophy and human experience.

The first version provides four witness groups and a local evidence ledger. Claims can be recorded with their source, supporting evidence, counter-evidence and a provisional assessment.

The site is configured as a Progressive Web App with a web app manifest, app icon, service worker registration and offline caching. Open it over HTTPS in Chrome and use the browser menu to add it to the home screen.
